Prerequisites: Windows, Node.js 24 at C:\Program Files\nodejs, and a working DreamSkin launcher exposing localhost:9335.
Copy your working DreamSkin desktop shortcut into this directory as 初见-原启动入口.lnk. Do not use the animation shortcut as its own original launcher.
Double-click Start.cmd. The HTML is a standalone preview. The GIF is an earlier preview; cold startup is not yet verified.
